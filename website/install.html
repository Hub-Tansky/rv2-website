Downloads

  • All files on the GitHub releases page

Windows

Run roboviolence2-win-x64-msvc-setup.exe.

Until we ship the first release signed with a certificate, the installer is unsigned. On "Windows protected your PC" (SmartScreen) choose More info → Run anyway.

macOS

Open roboviolence2-macos-arm64.dmg and drag Robo Violence 2 to Applications.

The app is unsigned, so Gatekeeper blocks the first start. Open System Settings → Privacy & Security and click Open Anyway.

Linux

Ubuntu, Mint, Debian: install roboviolence2-linux-x64.deb, then start Robo Violence 2 from the applications menu.

Other distributions: unpack roboviolence2-linux-x64.tar.gz and start run-client.sh.

More detail, troubleshooting and building from source: build guides.

Minimal system requirements

  • Windows 10 22H2 or later (x64).
  • macOS 12 or later with Apple Silicon (M1 or newer).
  • Linux x64 with glibc 2.39 or newer: Linux Mint 22, Ubuntu 24.04, Debian 13 or later.
