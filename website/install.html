Install Robo Violence 2

Alpha: in-progress experimental version with placeholder art. For now we recommend using your own original BaboViolent 2 data.

Download

Original game data

  1. Download the original game: BaboViolent2-master.zip.
  2. Unzip it into your Downloads, Desktop or Documents folder. Robo Violence 2 finds it there on start.
  3. Otherwise, the game asks on first start: choose BaboViolent2-master/BaboViolent2/Content/main/ or any folder above it.

Downloads

  • All files on the GitHub releases page

Windows

Run roboviolence2-win-x64-msvc-setup.exe. It installs for your user only and adds a Start-menu entry.

Until we ship the first release signed with a certificate, the installer is unsigned. On "Windows protected your PC" (SmartScreen) choose More info → Run anyway.

macOS

Open roboviolence2-macos-arm64.dmg and drag Robo Violence 2 to Applications.

The app is unsigned, so Gatekeeper blocks the first start. Open System Settings → Privacy & Security and click Open Anyway, or run:

xattr -dr com.apple.quarantine "/Applications/Robo Violence 2.app"

To run a game server on a Mac, get roboviolence2-macos-arm64.zip from the same release (Own server).

Linux

Ubuntu, Mint, Debian: install roboviolence2-linux-x64.deb, then start Robo Violence 2 from the applications menu.

sudo apt install ./roboviolence2-linux-x64.deb

Other distributions: unpack the .tar.gz and start:

tar -xzf roboviolence2-linux-x64.tar.gz
cd roboviolence2-linux-x64
./run-client.sh

More detail, troubleshooting and building from source: build guides.

Minimal system requirements

  • Windows 10 22H2 or later (x64).
  • macOS 12 or later with Apple Silicon (M1 or newer).
  • Linux x64 with glibc 2.39 or newer: Linux Mint 22, Ubuntu 24.04, Debian 13 or later.
