# 0035: The website uses Tailwind from its CDN, has a separate install guide and publishes files for AI agents

- Status: Accepted
- Date: 2026-10-23
- Affects: `website/`, `tools/website-markdown.mjs`, `tests/website/site.test.mjs`, `.github/workflows/pages.yml`, `packaging/discord_release_post.py`; amends ADR 0029

## Context
- Owner request 2026-10-23 (thread "Website v0.2"): Tailwind CSS from `cdn.tailwindcss.com` with no stylesheet files, Lucide or Font Awesome icons from a CDN, the current colours, a layout for 360 px phones, 768 px tablets and 1366-1920 px desktops with content in a ~1200 px container, a working mobile menu, the install section as its own page, and the isitagentready.com checks: robots.txt with AI crawler groups and Content Signals, a sitemap, Markdown for agents, Link headers, plus llms.txt, VideoGame JSON-LD and Open Graph tags.
- GitHub Pages sets no custom response headers and does no content negotiation. Cloudflare serves the zone DNS only; its Markdown for Agents needs the Pro plan, above the EUR 10 a month cap (ADR 0029).

## Decision
- Every page loads the Tailwind Play CDN pinned to 3.4.17 (`cdn.tailwindcss.com/3.4.17`: `theme.js` uses the v3 config and plugin API), then `theme.js` (palette, layout steps `md` 768 px and `xl` 1366 px, `max-w-site` 1200 px, the page chrome as component classes (`.site-header`, `.menu`, `.site-footer`, `.page`) and shared ones such as `.btn-primary`, `.card`, `.link` and `.prose-rv`), then Lucide 1.49.0 from jsDelivr. `style.css` is gone. `site.js` stays the one tested module for all pages (the owner's single-file wish covers markup and styling; five pages share the logic).
- `install.html` holds the old `#install` section, the requirements and the download note (version, file, size); the landing page keeps only the button. `/#install` redirects to `install.html`.
- Agent files: `robots.txt` (search and assistant fetchers allowed, training crawlers refused, `Content-Signal: search=yes, ai-input=yes, ai-train=no` in every group), `sitemap.xml`, `llms.txt`, and a Markdown copy of each page (`<page>.md`) generated by `tools/website-markdown.mjs` and linked with `<link rel="alternate" type="text/markdown">`. Tests fail when a copy is stale, a page misses the sitemap or a robots.txt group lacks the signal.

## Consequences
- The Play CDN compiles styles in the browser (about 100 KB of script) and Tailwind calls it unsuited to production; each page paints its background colour first so there is no white flash. Browsers also contact cdn.tailwindcss.com and cdn.jsdelivr.net; the privacy policy names them.
- Markdown negotiation on `Accept: text/markdown` and `Link` response headers are not served: they need a proxy in front of Pages (for example a free Cloudflare Worker on a proxied record). The `.md` copies are ready for it.
- After a page change, run `node tools/website-markdown.mjs`.
- Rejected: Cloudflare Pro for Markdown for Agents (over budget); hand-written Markdown copies (drift, worst for the privacy policy); Google Fonts (another third party receiving visitor IPs).
